# simple_games_python

# 🎮 Python Games Collection

A collection of beginner-friendly games developed using Python.  
This repository contains different types of games, including classic games, arcade games, and browser-based games.

The projects were created to practice Python programming, game logic, problem-solving, and basic web technologies.

---

## 🎯 Games Included

### 1. 🔢 Number Guessing Game
A simple game where the computer generates a random number and the player tries to guess it.

**Features:**
- Random number generation
- Guess validation
- Higher/lower hints
- Attempt counter
- Restart option

---

### 2. ✊ Rock Paper Scissors
A classic Rock Paper Scissors game where the player competes against the computer.

**Features:**
- Rock, Paper and Scissors
- Computer opponent
- Score tracking
- Win/Loss/Draw system
- Restart option

---

### 3. ❌⭕ Tic-Tac-Toe
A two-player Tic-Tac-Toe game using a 3×3 board.

**Features:**
- Two-player gameplay
- Turn-based system
- Win detection
- Draw detection
- Restart game

---

### 4. 🐍 Snake Game
A browser-based Snake game where the player controls a growing snake and collects food.

**Features:**
- Keyboard controls
- Food collection
- Score system
- Collision detection
- Increasing challenge
- Game over and restart

---

### 5. 🏎️ Car Racing Game
A simple 2D car racing game where the player avoids incoming vehicles.

**Features:**
- Player car
- Enemy cars
- Road animation
- Keyboard controls
- Score system
- Collision detection
- Increasing difficulty

---

### 6. 🐦 Flappy Bird-Style Game
A simple arcade game inspired by the mechanics of classic flying games.

**Features:**
- Gravity and jumping
- Moving obstacles
- Score tracking
- Collision detection
- Increasing difficulty
- Restart option

> This project uses original game elements and is not a copy of the original game's artwork or assets.

---

### 7. 🚀 Space Shooter
A browser-based shooting game where the player controls a spaceship and fights incoming enemies.

**Features:**
- Player spaceship
- Enemy spaceships
- Shooting system
- Score tracking
- Lives system
- Collision detection
- Increasing difficulty
- Game over and restart

---

### 8. ⚡ Monster Battle
A Pokémon-style turn-based battle game using original creatures.

**Features:**
- Player creature
- Enemy creature
- Turn-based combat
- Attack and special attack
- Healing
- HP system
- XP and leveling
- Victory and defeat system

> The creatures and game assets are original and are not official Pokémon characters or assets.

---

### 9. 🗺️ 2D Monster Adventure
A Pokémon-style 2D adventure concept featuring exploration and creature encounters.

**Planned/Implemented Features:**
- 2D top-down map
- Player movement
- Grass areas
- Trees and obstacles
- Random creature encounters
- Turn-based battles
- HP system
- XP and leveling
- Inventory system
